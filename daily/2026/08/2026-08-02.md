## 비고
> DP 재활 훈련 1일차
> 0. dp 부터 생각하지 말고 재귀부터 생각한다
> 1. 상태 정의
>       - solve(i) 또는 dp[i]가 정확히 무엇을 의미하는가?
> 2. 현재 상태에서 가능한 선택
>       - i에서 어떤 행동을 할 수 있는가?
> 3. 다음 상태
>       - 각 선택을 하면 인덱스나 상태가 어떻게 변하는가?
> 4. 점화식
>       - 현재 답을 이전 또는 다음 상태로 어떻게 표현하는가?
> 5. 종료 조건 / 초기값
>       - 가장 작은 문제의 답은 무엇인가?
> 6. 정답 위치
>       - dp[n]인가?
>       - dp[n - 1]인가?
>       - 전체 dp 중 최댓값인가?
> 7. 시간·공간 복잡도
> 8. 재귀 → 메모이제이션 → 반복문
>       - 가능하면 세 방식의 관계를 확인 


## 정리
### 코딩 테스트
- Climbing Stairs

    0. DP가 아닌 재귀로 생각한다
        - 문제를 쪼개자
        - 문제 = 0층에서 n층으로 가는 경우의 수
        - 부분 문제 0층에서 n-1층으로 가는 경우의 수
    1. 상태 정의
        - solve(i): i층으로 가는 경우의 수
    2. 현재 상태에서 가능한 선택
        - 1칸 위로 가거나, 2칸 위로 갈 수 있다
    3. 다음 상태
        - i-1 층
        - i-2 층
    4. 점화식
        - solve(i) = solve(i-1) + solve(i-2);
    5. 종료 조건 / 초기값
        - 종료 조건
            - solve(1) = 1;
            - solve(2) = 2;
    6. 정답 위치
        - solve(n)
    7. 시간·공간 복잡도
        - 재귀
            - 한 재귀에서 2번의 재귀문을 호출하므로, O(2^n)
        - 메모이제이션 / 반복문
            - 각 층에 대해 1회만 계산하므로, O(n)
    8. 재귀 → 메모이제이션 → 반복문
        ```cpp
        // 재귀
        int solve(int i){
            if(i == 1) return 1;
            if(i == 2) return 2;
            return solve(i-1) + solve(i-2);
        }

        // 메모이제이션
        int cache[46];
        int solve(int i){
            if(i == 1) return 1;
            if(i == 2) return 2;
            if(cache[i] != -1) return cache[i];

            return cache[i] = solve(i-1) + solve(i-2);
        }

        // 반복문
        int dp[46];
        dp[0] = 0;
        dp[1] = 1;
        dp[2] = 2;
        for(int i = 3;i<=n;i++){
            dp[i] = dp[i-1] + dp[i-2];
        }
        return dp[n];
        ```
