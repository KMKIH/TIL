## 비고
> DP 재활 훈련 3일차
> 0. dp 부터 생각하지 말고 재귀부터 생각한다
> 1. 상태 정의
>       - solve(i) 또는 dp[i]가 정확히 무엇을 의미하는가?
> 2. 현재 상태에서 가능한 선택
>       - i에서 어떤 행동을 할 수 있는가?
> 3. 다음 상태
>       - 각 선택을 하면 인덱스나 상태가 어떻게 변하는가?
> 4. 점화식
>       - 현재 답을 이전 또는 다음 상태로 어떻게 표현하는가?
> 5. 종료 조건 / 초기값
>       - 가장 작은 문제의 답은 무엇인가?
> 6. 정답 위치
>       - dp[n]인가?
>       - dp[n - 1]인가?
>       - 전체 dp 중 최댓값인가?
> 7. 시간·공간 복잡도
> 8. 재귀 → 메모이제이션 → 반복문
>       - 가능하면 세 방식의 관계를 확인 


## 정리
### 코딩 테스트
- Minimum Path Sum
    > 바로 DP 풀이가 생각나서 생략
    1. dp[i][j] : (i, j) 위치로 이동하는 최소 값
    2. 점화식
        ```cpp
        dp[i][j] = min(dp[i-1][j], dp[i][j-1]) + grid[i][j];
        ```
    3. 정답 위치
        - dp[n-1][m-1]
    4. ~~재귀 → 메모이제이션 → ~~반복문
        ```cpp
        // 반복문
        int minPathSum(vector<vector<int>>& grid) {
            int n = grid.size();
            int m = grid[0].size();

            int dp[201][201];
            dp[0][0] = grid[0][0];

            for(int i = 0;i<n;i++){
                for(int j = 0;j<m;j++){
                    if(i == 0 && j == 0)dp[i][j] = grid[i][j];
                    else if(i == 0){
                        dp[i][j] = dp[i][j-1] + grid[i][j];
                    }
                    else if(j == 0){
                        dp[i][j] = dp[i-1][j] + grid[i][j];
                    }
                    else{
                        dp[i][j] = min(dp[i-1][j],dp[i][j-1]) + grid[i][j];
                    }
                }
            }
            return dp[n-1][m-1];
        }
        ```
- Word Break
    1. 문제 접근
        - BruteForce로 생각해보자
            - 문자열을 순회하면서 가능한 경우에 수에 대해 모두 시도해보자
        - 중복되는 경우를 생각해보자
            - 특정 문자열이 wordDict로 구성될 수 있다면 그 문자열에 대한 결과값을 저장하자
    2. dp[i]: s[0~i]를 wordDict의 문자들로 구성할 수 있는가?
    ```cpp
        class Solution {
        private:
            bool compare(const string& s, int sidx, const string& word){
                for(int i = 0; i <word.size();i++){
                    if(s[sidx+i] != word[i]) return false;
                }
                return true;
            }
        public:
            bool wordBreak(string s, vector<string>& wordDict) {
                vector<bool> dp(s.size()+1, false);
                dp[0] = true;
                for(int i = 1; i <= s.size(); i++){
                    for(int j = 0; j < wordDict.size(); j++){
                        const string& word = wordDict[j];
                        int n = word.size();
                        if(i < n) continue;
                        if(compare(s, i-n, word)){
                            dp[i] = dp[i] | dp[i-n];
                        }
                    }
                }
                return dp[s.size()];
            }
        };    
    ```
