## 정리
### 코딩 테스트
- Koko Eating Bananas
    - 문제 접근
        1. k값을 찾아야겠네
        2. k값을 구하고, 해당 k값을 사용했을때 h값을 구하면 되겠네
            1. BruteForce?
                - 시간복잡도 상으로 될거같긴한데 좀 빡빡할지도
            2. 이분탐색
                - 임의의 k값에 대하여 h값이 크면 k값을 키우고, h값이 작으면 k값을 줄이면 되겠네
    - 구현
        ```cpp
        class Solution {
        private:
            long long checkCondition(vector<int>& piles, int k){
                long long ret = 0;
                for(int b : piles){
                    if(b % k == 0) ret += b/k;
                    else ret += b/k + 1;
                }
                return ret;
            }
        public:
            int minEatingSpeed(vector<int>& piles, int h) {
                sort(piles.begin(),piles.end());
                int s = 1;
                int e = *piles.rbegin();

                int ret = 0;
                while(s <= e){
                    int k = s + (e-s)/2;
                    if(checkCondition(piles, k) <= h){
                        ret = k;
                        e = k-1;
                    }
                    else{
                        s = k+1;
                    }
                }
                return ret;
            }
        };
        ```
