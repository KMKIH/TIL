## 정리
### 코딩 테스트
- Solving Questions With Brainpower
    > 0. dp 부터 생각하지 말고 재귀부터 생각한다
    - 문제 정리
        - i번째 문제를 풀면 points[i]만큼의 점수를 얻지만 다음 brainpower[i]만큼의 문제를 풀 수 없다
    > 1. 상태 정의
    - solve(i) = i번째 문제까지 왔을때, 최대 점수
    > 2. 현재 상태에서 가능한 선택
    - 현재 문제를 푼다
    - 현재 문제를 풀지 않는다
    > 3. 다음 상태
    - 현재 문제를 푸는 경우
        - brainpower[i]이후의 문제에 대해 풀지 말지 결정한다
    - 현재 문제를 풀지 않는 경우
        - 다음 문제에 대해 풀지 말지 결정한다
    > 4. 점화식
    - solve(i) = max(solve(i + bp + 1)+pt, solve(i+1))
    > 5. 재귀 → 메모이제이션 → 반복문
    - 메모이제이션
    ```cpp
    class Solution {
    private:
        vector<long long> cache;
        long long solve(vector<vector<int>>& questions, int i){
            if(i >= questions.size()) return 0;
            long long& ret = cache[i];
            if(ret != -1) return ret;
            ret = 0;

            int bp = questions[i][1]+1;
            int pt = questions[i][0];
            return ret = max(solve(questions,i+bp)+pt,solve(questions,i+1));
        }
    public:
        long long mostPoints(vector<vector<int>>& questions) {
            cache = vector<long long>(questions.size(),-1);
            return solve(questions, 0);
        }
    };
    ```
    - dp
        - 이후의 정보를 통해 이전 정보가 결정된다
        - 따라서 문제를 뒤에서부터 접근한다
    ```cpp
    class Solution {
    public:
        long long mostPoints(vector<vector<int>>& questions) {
            int n = questions.size();
            vector<long long> dp(n+1,0);

            for(int i = n-1;i >=0;i--){
                int bp = questions[i][1]+1;
                int pt = questions[i][0];

                long long solve = pt;
                if(i + bp < n) solve += dp[i+bp];

                long long pass = dp[i+1];

                dp[i] = max(solve, pass);
            }
            return dp[0];
        }
    };
    ```
