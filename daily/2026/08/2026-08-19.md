### 코딩 테스트
- Merge Intervals
    - 문제 접근
        - 시작 시간을 기준으로 정렬하자
        - 시작 시간이 먼저인 것부터 검사하고, 다음 요소와 겹치는지 확인한다
            - 겹친다면, 현재 구간과 병합하고, 병합된 구간을 이후 구간과 계속 비교한다.
            - 겹치지 않는다면, 정답 배열에 넣는다
    - 구현
        ```cpp
        class Solution {
        public:
            vector<vector<int>> merge(vector<vector<int>>& intervals) {
                sort(intervals.begin(), intervals.end());

                vector<vector<int>> ret;
                ret.push_back({intervals[0][0], intervals[0][1]});
                for(int i = 1;i < intervals.size();i++){
                    auto itr = ret.end()-1;
                    int s1 = (*itr)[0];
                    int e1 = (*itr)[1];

                    int s2 = intervals[i][0];
                    int e2 = intervals[i][1];

                    if(e1 >= s2){
                        (*itr)[0] = s1 > s2? s2:s1;
                        (*itr)[1] = e1 > e2 ? e1 : e2;
                    }
                    else{
                        ret.push_back({s2,e2});
                    }
                }
                return ret;
            }
        };
        ```
    - Daily Temperatures
        - 문제 접근
            - 가장 먼저 단조 스택이 생각이남
            - 만약 Brute Force로 접근한다면 O(N^2)으로 시간 초과 가능성이 있음
        - 문제 정리
            - 나보다 오른쪽에 있는 큰 수 중에서 가장 가까운 수를 찾는 문제
        - **단조 스택을 사용한 풀이가 아직 직관적으로 떠오르지 않음**
            - 왜 단조 스택인가?
                - i번째 수를 기준으로 찾을떄, i+1부터 n번째 숫자만 보면된다.
                - [i+1..n] 구간을 단조스택으로 만들어야한다
                    - 중간에 작아지는 수는 의미가 없다.
                        - 자신보다 큰 숫자가 이미 왼쪽에 존재하기때문에 자신이 선택될일이 없다
        - 시간 복잡도
            - 대략적인 형태는 아래와 같아서 O(N)처럼 보이지만, 각 원소가 스택에서 이루어지는 push와 pop은 최대 1번씩만 발생한다.
                ```cpp
                for(...){
                    while(...){

                    }
                }
                ```
            - 따라서 시간복잡도는 O(N)이다
                
        - 구현
            ```cpp
                class Solution {
                public:
                    vector<int> dailyTemperatures(vector<int>& temperatures) {
                        int n = temperatures.size();
                        stack<pair<int,int>> s; // t, idx
                        vector<int> ret(n,0);
                        
                        for(int i = n-1;i>=0;i--){
                            int t = temperatures[i];
                            if(s.empty()){
                                ret[i] = 0;
                                s.push({t,i});
                            }
                            else if(s.top().first > t){
                                ret[i] = s.top().second - i;
                                s.push({t,i});
                            }
                            else{
                                while(s.empty()==false && s.top().first <= t){
                                    s.pop();
                                }
                                if(s.empty())ret[i] = 0;
                                else ret[i] = s.top().second - i;

                                s.push({t,i});
                            }
                        }
                        return ret;
                    }
                };
            ```
