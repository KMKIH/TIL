## 정리
### 코딩 테스트
- Minimum Cost For Tickets
    > 0. dp 부터 생각하지 말고 재귀부터 생각한다
    - 문제 정리
        - 각 날짜에 대해 1-day pass/7-day pass/30-day pass 중 하나를 선택한다
    - 비고
        - 어제 풀었던 문제처럼 이후의 정보가 현재 정답을 결정한다
    > 1. 상태 정의
    - solve(i) = i번째 날짜에 왔을때 최소 비용
    > 2. 현재 상태에서 가능한 선택
    - 1일권/7일권/30일권 선택
    > 3. 다음 상태
    - pass가 적용되지 않는 다음 날짜를 선택한다
    > 4. 점화식
    - solve(i) = min(solve(next1),solve(next2),solve(next3))
        - next1, next2, next3는 pass가 적용되지 않은 바로 다음 날짜의 인덱스이다
        - 이 인덱스를 구하기 위해 BinarySearch를 사용한다 (lower_bound(i+1/7/30))
    ```cpp
    class Solution {
    private:
        vector<int> cache;
        int binarysearch(vector<int>& days, int value){
            auto itr = lower_bound(days.begin(), days.end(), value);
            if(itr == days.end())return days.size();
            return itr-days.begin();
        }
        int solve(vector<int>& days,vector<int>& costs,int idx){
            if(idx >= days.size()) return 0;
            int& ret = cache[idx];
            if(ret != -1) return ret;

            ret = 987654321;
            // 1일권
            int idx1 = binarysearch(days,days[idx]+1);
            ret = min(ret, solve(days,costs,idx1)+costs[0]);

            // 7일권
            int idx7 = binarysearch(days,days[idx]+7);
            ret = min(ret, solve(days,costs,idx7)+costs[1]);
            
            // 30일권
            int idx30 = binarysearch(days,days[idx]+30);
            ret = min(ret, solve(days,costs,idx30)+costs[2]);
            
            return ret;
        }
    public:
        int mincostTickets(vector<int>& days, vector<int>& costs) {
            cache = vector<int>(366,-1);
            return solve(days,costs,0);
        }
    };
    ```
