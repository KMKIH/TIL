## 정리
### 코딩 테스트
- Coin Change
    1. 문제 접근
        - 어떤 값에 대해 하나의 코인을 추가로 사용하면 그게 최소아닌가?
        - 각 값에 대해 최소 몇개의 코인으로 만들수있는지 계산하자
    2. dp[i]: i를 구성하기 위해 필요한 코인의 최소 갯수
        > dp[i] = min(dp[i], dp[i-coin] + 1)
    ```cpp
        #include <limits>

        class Solution {
        public:
            int coinChange(vector<int>& coins, int amount) {
                const int MAXVALUE = numeric_limits<int>::max();
                vector<int> dp(amount+1, MAXVALUE);

                dp[0] = 0;
                for(int i = 1;i<=amount;i++){
                    for(int j = 0;j<coins.size();j++){
                        int coin = coins[j];
                        if(i < coin || dp[i-coin] == MAXVALUE)continue;
                        dp[i] = min(dp[i], dp[i-coin] + 1);
                    }
                }
                if(dp[amount] == MAXVALUE) return -1;
                return dp[amount];
            }
        };
    ```
- Longest Increasing Subsequence
    1. 문제 접근
        - 임의의 위치에서 그전 숫자들과 비교해서 부분 수열의 길이를 구할 수 있다
    2. dp[i] = i번을 끝으로 하는 부분 수열의 최대 길이
    3. 정답 위치
        - 모든 dp를 순회하여 최대값을 찾는다
    4. DP
        ```cpp
            class Solution {
            public:
                int lengthOfLIS(vector<int>& nums) {
                    int n = nums.size();

                    vector<int> dp(n,1);
                    for(int i = 1;i<n;i++){
                        for(int j = 0;j<i;j++){
                            if(nums[j] < nums[i]) dp[i] = max(dp[i],dp[j]+1);
                        }
                    }

                    int ret = 0;
                    for(int i = 0;i<n;i++){
                        ret = max(ret, dp[i]);
                    }
                    return ret;
                }
            };
        ```
    ---
    #### 다른 풀이 방법
    - LIS - 이분 탐색 풀이
        - 핵심 아이디어
            > 길이별로 가장 작은 마지막 값만 관리한다
            > - 각 길이의 부분 수열을 앞으로 가장 확장하기 좋은 상태로 저장한다
        - 실제 접근 방법
            1. 현재 숫자(num)이상인 첫번째 위치를 찾는다
            2. 그런 위치가 있다면 num으로 교체한다
            3. 그런 위치가 없으면 뒤에 num을 추가한다
            > 값을 더 작게 교체한다 -> 더 많은 숫자를 연결할 수 있다 (작아지므로)
        - 의문
            - "num으로 교체한다" -> 순서가 뒤바뀌는 일은 없나?
                > tails는 실제 부분 수열을 저장하는 배열이 아니라, 각 길이의 증가 부분 수열이 가질 수 있는 최소 마지막 값을 저장하는 배열이다.
        - 풀이
        ```cpp
            class Solution {
            public:
                int lengthOfLIS(vector<int>& nums) {
                    vector<int> tail;

                    for(int n : nums){
                        auto itr = lower_bound(tail.begin(),tail.end(), n);
                        if(itr == tail.end()) tail.push_back(n);
                        else *itr = n;
                    }
                    return tail.size();
                }
            };
        ```
