## 정리
### 코딩 테스트
- Longest Substring Without Repeating Characters
    - 문제 접근
        - 유효한 부분 문자열을 찾는다
            - 유효하다 = 중복되는 문자가 없다
            - 현재 상태에서 문자의 개수를 관리하자
    - 구현
        ```cpp
            class Solution {
            public:
                int lengthOfLongestSubstring(string s) {
                    int l = 0;
                    int ret = 0;

                    map<int,int> cnt;
                    for(int r = 0;r<s.size();r++){
                        cnt[s[r]]++;
                        while(cnt[s[r]]>1){
                        cnt[s[l]]--;
                            l++;
                        }
                        ret = max(ret, r-l+1);
                    }
                    return ret;
                }
            };
        ```
        - 최적화 1
            > char형의 크기는 1byte(8bit)로 256개의 숫자를 표현할 수 있다
            > 따라서 map을 사용하지 않고 256의 크기를 가지는 벡터로 표현할 수 있다
        - 최적화 2
            > Point : 개수를 저장해야할까?
            > => 모든 값을 알 필요는 없다

            > 해당 문자가 나타난 마지막 위치를 알면 substr의 길이를 쉽게 구할 수 있다
            ```cpp
            class Solution {
            public:
                int lengthOfLongestSubstring(string s) {
                    vector<int> last(256, -1);  // 문자가 나타난 마지막 위치
                    int left = 0, maxLen = 0;

                    for (int right = 0; right < s.length(); right++) {
                        if (last[s[right]] >= left) {
                            left = last[s[right]] + 1;
                        }

                        last[s[right]] = right;
                        maxLen = max(maxLen, right - left + 1);
                    }

                    return maxLen;
                }
            };

            ```
