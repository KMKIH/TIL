## 정리
### 코딩 테스트
- Subarray Sum Equals K
    - 문제 접근
        1. 백트래킹
            - 문제를 훑어봤을때, 원소를 선택하는 문제라고 오해했음
            - 백트래킹으로 문제를 선택하면 되겠구나...!
            - 근데, 연속된 원소를 선택하는 문제라 굳이 백트래킹을 사용하지 않아도되었다
        2. 반복문
            - 일단 가장 간단한 방법으로 접근해보자
            - 2중 for문으로 모든 경우에 수에 접근해보자
            - 시간 초과는 나지 않았지만, 거의 시간 초과라도 봐도 될듯..
        3. 누적합
            - 연속된 원소들의 합을 보는 문제이다
            - 2중 for문으로 범위의 누적합을 구할 수 있지만, 2번 풀이법과 유사해진다
            - 누적합을 1회만 구하고, 이를 활용할 수 있는 방법을 찾아보자

            > 힌트를 봤음
            - [0..i]로 누적합을 구한다
            - [0..i] 누적합 2개의 차를 통해 범위내 누적합을 구할 수 있다
                - [0..j] - [0..i-1] = [i..j] (i<j)
            - 이 방법을 통해 subarray의 합이 k인 개수를 구해보자
                1. [0..j]를 B, [0..i-1]를 A라고 하자
                2. B-A = k인 요소를 찾는다
                3. 앞에서부터 누적합을 찾는다
                4. 임의의 B에 대해 해당하는 A가 있는지 찾는다
                    - A = B-k
    - 구현
        ```cpp
        class Solution {
        public:
            int subarraySum(vector<int>& nums, int k) {
                int n = nums.size();
                int prefixSum = 0;
                unordered_map<int,int> m;
                
                int ret = 0;
                m[0] = 1;
                for(int i = 0;i<n;i++){
                    prefixSum = prefixSum + nums[i];
                    ret += m[prefixSum-k];
                    m[prefixSum]++;
                }
                return ret;
            }
        };
        ```
