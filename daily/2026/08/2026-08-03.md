## 비고
> DP 재활 훈련 2일차
> 0. dp 부터 생각하지 말고 재귀부터 생각한다
> 1. 상태 정의
>       - solve(i) 또는 dp[i]가 정확히 무엇을 의미하는가?
> 2. 현재 상태에서 가능한 선택
>       - i에서 어떤 행동을 할 수 있는가?
> 3. 다음 상태
>       - 각 선택을 하면 인덱스나 상태가 어떻게 변하는가?
> 4. 점화식
>       - 현재 답을 이전 또는 다음 상태로 어떻게 표현하는가?
> 5. 종료 조건 / 초기값
>       - 가장 작은 문제의 답은 무엇인가?
> 6. 정답 위치
>       - dp[n]인가?
>       - dp[n - 1]인가?
>       - 전체 dp 중 최댓값인가?
> 7. 시간·공간 복잡도
> 8. 재귀 → 메모이제이션 → 반복문
>       - 가능하면 세 방식의 관계를 확인 


## 정리
### 코딩 테스트
- House Robber
    
    0. DP가 아닌 재귀로 생각한다
        - 문제를 쪼개자
            - 문제 = n-1번째 집까지 털었을때 최대값
            - 부분 문제 = i번째 집까지 털었을때 최대값
    1. 상태 정의
        - solve(i): i번째 집까지 털었을때 최대값
    2. 현재 상태에서 가능한 선택
        - 현재 집을 턴다
        - 현재 집을 털지 않는다
    3. 다음 상태
        - 다음 집에 대해서 위 선택을 고민한다
    4. 점화식
        - 현재 집을 턴다
            - 이전 집을 털지 않는다
            - solve(i) = solve(i-2) + nums[i]
        - 현재 집을 털지 않는다
            - 이전 값을 사용한다
            - solve(i) = solve(i-1)
        - solve(i) = max(solve(i-1), solve(i-2) + nums[i])
    5. 종료 조건 / 초기값
        - solve(0) = nums[0]
        - solve(1) = max(nums[0], nums[1]);
    6. 정답 위치
        - solve(n-1)
    7. 시간·공간 복잡도
        - 재귀
            - 한 재귀에서 2번의 재귀문을 호출하므로, O(2^n)
        - 메모이제이션 / 반복문
            - 각 층에 대해 1회만 계산하므로, O(n)
    8. 재귀 → 메모이제이션 → 반복문
        ```cpp
        // 재귀
        int solve(int i){
            if(i <= 1) return nums[i];
            return max(solve(i-1), solve(i-2) + nums[i]);
        }

        // 메모이제이션
        int cache[101];
        int solve(int i){
            if(i <= 1) return nums[i];
            if(cache[i] != -1) return cache[i];

            return cache[i] = max(solve(i-1), solve(i-2) + nums[i]);
        }

        // 반복문
        int dp[101];
        dp[0] = nums[0];
        dp[1] = max(nums[0],nums[1]);
        for(int i = 2;i<n;i++){
            dp[i] = max(dp[i-1], dp[i-2] + nums[i]);
        }
        return dp[n-1];
        ```
- House Robber II
    - House Robber에서 아이디어 확장
    - 원형으로 구성되어있으므로
        - 0번째집을 선택하는 경우 (n-1번째 선택안함)
        - 0번째집을 선택하지 않는 경우 (n-1번째를 선택할 수 있음)
    ```cpp
        int dp[101];

        int n = nums.size();
        if(n == 1) return nums[0];
        if(n == 2) return max(nums[0],nums[1]);

        int ret1, ret2;
        dp[0] = nums[0];
        dp[1] = max(nums[0],nums[1]);
        for(int i = 2;i<n-1;i++){
            dp[i] = max(dp[i-1], dp[i-2] + nums[i]);
        }
        ret1 = dp[n-2];

        dp[1]  = nums[1];
        dp[2] = max(nums[1],nums[2]);
        for(int i = 3;i<n;i++){
            dp[i] = max(dp[i-1], dp[i-2] + nums[i]);
        }
        ret2 = dp[n-1];

        return max(ret1,ret2);
    ```
- Decode Ways
    
    0. DP가 아닌 재귀로 생각한다
        - 문제를 쪼개자
            - 문제 = n-1번째 문자까지 계산했을때 해석 가능한 경우의 수
            - 부분 문제 = i번째 문자까지 계산했을때 해석 가능한 경우의 수
    1. 상태 정의
        - solve(i): 문자까지 계산했을때 해석 가능한 경우의 수
    2. 현재 상태에서 가능한 선택
        - 현재 문자열만 해석한다
        - 이전 문자열까지 해석한다
    3. 다음 상태
        - 다음 문자열에 대해서 위의 과정을 거친다
    4. 점화식
        - 현재 문자열만 해석한다
            - solve(i) = solve(i-1)
        - 이전 문자열까지 해석한다
            - 이전 문자열이 2이하이여야한다
                - 2인 경우 현재 문자열이 6이하여야한다 
            - solve(i) = solve(i-2)
        - solve(i) = solve(i-1)+ solve(i-2) (조건부)
    5. 종료 조건 / 초기값
        - solve(0) = 1
        - solve(1) = (조건을 만족하면) 2 : 1;
    6. 정답 위치
        - solve(n-1)
    7. 시간·공간 복잡도
        - 재귀
            - 한 재귀에서 2번의 재귀문을 호출하므로, O(2^n)
        - 메모이제이션 / 반복문
            - 각 층에 대해 1회만 계산하므로, O(n)
    8. 재귀 → 메모이제이션 → 반복문
