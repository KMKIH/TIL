## 정리
### 코딩 테스트
- Longest Repeating Character Replacement
    - 문제 접근
        1. DP
            - 생각한 이유: idx와 변경한 횟수를 기반으로 상태를 설정
            - 안되는 이유:
                - idx와 변경 횟수를 상태로 지정했을때, 공간 제약
                - idx와 변경 횟수만으로 상태가 정의되는가?
                    - 현재 가장 많은 문자까지 저장을해야한다
            > 여기서 얻은 것: 현재 상태를 정의하기 위해서는 idx와 변경한 횟수, 그리고 현재 상태를 대표하는 문자가 필요하다
        2. 슬라이딩 윈도우
            - Window 정의
                > 현재 범위까지 기반으로 살펴본다
                - 다음 문자를 포함시켜 유효한지 확인한다
                    - 유효하다 : 현재 윈도우가 조건을 만족한다
                    - 유효하지않다: 현재 윈도우가 조건을 만족하지 못한다
            - 구현
                ```cpp
                class Solution {
                public:
                    int getMaxCount(vector<int>& alphabet){
                        int maxValue = -1;
                        for(int i = 0;i<alphabet.size();i++){
                            maxValue = max(maxValue, alphabet[i]);
                        }
                        return maxValue;
                    }
                    bool checkCondition(vector<int>& alphabet, int len, int k){
                        return len - getMaxCount(alphabet) <= k;
                    }
                    int characterReplacement(string s, int k) {
                        int l = 0;
                        int r = 0;
                        int ret = 0;

                        // 현재 대표 문자를 저장해야할듯
                        vector<int> alphabet(26,0);
                        alphabet[s[l]-'A'] = 1;

                        while(r < s.size()){
                            int len = r - l + 1;
                            // 유효한 Window라면, 윈도우를 확장한다
                            if(checkCondition(alphabet, len, k)){
                                ret = max(ret, len);
                                r++;
                                if(r < s.size()){
                                    alphabet[s[r]-'A']++;
                                }
                            }
                            // 유효하지 않은 Window라면, 윈도우를 축소한다
                            else{
                                alphabet[s[l]-'A']--;
                                l++;
                                maxFreq = 0;
                                for(int i = 0; i < 26; i++){
                                    maxFreq = max(maxFreq, alphabet[i]);
                                }
                            }
                        }
                        return ret;
                    }
                };
                ```

        4. 슬라이딩 윈도우 - 최적화 2
            > 현재 대표 문자를 항상 전체를 돌면서 계산해야하는가?
            > => 계산시마다 갱신해주자
        5. 구현 2
            ```cpp
            class Solution {
            public:
                int characterReplacement(string s, int k) {
                    int l = 0;
                    int maxFreq = 0;
                    int ret = 0;

                    // 현재 대표 문자 계산용 배열
                    vector<int> alphabet(26,0);

                    for(int r = 0;r<s.size();r++){
                        int len = r-l+1;
                        alphabet[s[r]-'A']++;
                        
                        maxFreq = max(maxFreq, alphabet[s[r]-'A']);
                        if(len - maxFreq <= k){
                            ret = max(ret,len);
                        }
                        else{
                            alphabet[s[l]-'A']--;
                            l++;
                            maxFreq = 0;
                            for(int i = 0; i < 26; i++){
                                maxFreq = max(maxFreq, alphabet[i]);
                            }
                        }
                    }
                    return ret;
                }
            };
            ```
        6. 슬라이딩 윈도우 - 최적화 3
            > l 이동시 maxFreq 계산이 필요한가?
            > =>정답이 최대 길이만 필요하다는 특성 때문에 재계산을 생략할 수 있음
            > => maxFreq를 과거의 최댓값으로 유지하면 현재 윈도우를 실제보다 유효하다고 판단할 수는 있지만, 이미 이전에 달성했던 길이를 유지하는 정도일 뿐 존재하지 않는 더 큰 정답을 만들지는 않는다.
