## 비고
> DP 재활 훈련 5일차
> 0. dp 부터 생각하지 말고 재귀부터 생각한다
> 1. 상태 정의
>       - solve(i) 또는 dp[i]가 정확히 무엇을 의미하는가?
> 2. 현재 상태에서 가능한 선택
>       - i에서 어떤 행동을 할 수 있는가?
> 3. 다음 상태
>       - 각 선택을 하면 인덱스나 상태가 어떻게 변하는가?
> 4. 점화식
>       - 현재 답을 이전 또는 다음 상태로 어떻게 표현하는가?
> 5. 종료 조건 / 초기값
>       - 가장 작은 문제의 답은 무엇인가?
> 6. 정답 위치
>       - dp[n]인가?
>       - dp[n - 1]인가?
>       - 전체 dp 중 최댓값인가?
> 7. 시간·공간 복잡도
> 8. 재귀 → 메모이제이션 → 반복문
>       - 가능하면 세 방식의 관계를 확인 

## 정리
### 코딩 테스트
- Partition Array for Maximum Sum
    - 문제 정리
        - Subarray의 길이가 최대 k일때 (at most K) 최대값
    - 문제 접근
        - 현재 위치까지 계산한다 했을때, k가지의 경우의 수가 있다. (현재 위치를 포함하는 k개의 subarray)
        - dp[i] = 현재 위치까지의 최대값
        ```cpp
        class Solution {
        public:
            int maxSumAfterPartitioning(vector<int>& arr, int k) {
                int dp[501] = {0};
                int MAXVALUE[501][501] = {0};

                // get MaxValue
                int n = arr.size();
                for(int i = 0;i<n;i++){
                    for(int j = i;j<n;j++){
                        if(j == 0) MAXVALUE[i][j] = arr[i];
                        else MAXVALUE[i][j] = max(MAXVALUE[i][j-1],arr[j]);
                    }
                }

                // dp
                for(int i = 0; i< n;i++){
                    for(int j = 1;j <= k;j++){
                        int bef = i - j;
                        if(bef == -1) dp[i] = MAXVALUE[0][i]*(i+1);
                        else if(bef >= 0) {
                            dp[i] = max(dp[i], dp[bef] + MAXVALUE[bef+1][i] * j);
                        }
                    }
                }
                return dp[n-1];
            }
        };
        ```
