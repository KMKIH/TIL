## 정리
### 코딩 테스트
- Next Permutation
    - 문제 접근
        - 뒤에서부터 살펴보면서, 더 큰 수를 만들 수 있는지 확인
        - 더 큰 수를 만들 수 있다면,
            1. 현재 보고 있는 위치의 수보다 큰 다음수를 선택한다
            2. Swap한다
            3. 그 뒤의 수들은 오름차순으로 정렬시킨다
    - 구현
        ```cpp
        class Solution {
        public:
            void nextPermutation(vector<int>& nums) {
                int n = nums.size();
                for(int i = n-2; i >= 0; i--){
                    int cur = nums[i];
                    int next = 987654321;
                    int nextIdx = -1;
                    for(int j = i+1; j < n; j++){
                        if(cur < nums[j] && next > nums[j]){
                            next = nums[j];
                            nextIdx = j;
                        }
                    }
                    if(next != 987654321) {
                        swap(nums[i],nums[nextIdx]);
                        sort(nums.begin()+i+1, nums.end());
                        return;
                    }
                }
                
                // 다음 순열이 없다
                sort(nums.begin(), nums.end());
            }
        };
        ```
    - 다른 풀이 방법
        > 순열의 뒷 부분은 **내림차순**이다
        - 이 방법을 이용해,
            1. 뒤에서부터 nums[i] < nums[i+1]인 가장 오른쪽 i를 찾는다
            2. 뒤에서부터 nums[i]보다 큰 첫 원소를 찾아 swap한다
                - i이후로는 이미 내림차순이므로, 배열을 전부 순회하지 않아도된다
            3. i+1 이후를 reverse한다
                - i+1 이후로는 이미 내림차순인데, swap한다고 해서 내림차순이 변하지는 않는다
    - 시간 복잡도
        - 기존 풀이: O(N^2)
        - 개선 풀이: O(N)
        > => 내림차순이라는 특징을 이용해 불필요한 탐색 및 정렬을 줄일 수 있다
        > - sort -> reverse
