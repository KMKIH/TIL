## 정리
### 코딩 테스트
- Delete and Earn
    1. BruteForce
        - 모든 숫자에 대해서 경우의 수를 모두 시도해본다
        - BackTracking
        ```cpp
        class Solution {
        private:
            int maxValue = 0;
            int minValue = 0;
            int arr[10001] = {0};
            int rec(int cur){
                int ret = 0;
                for(int i = cur == -1? minValue : cur; i<=maxValue;i++){
                    if(arr[i] <= 0) continue;
                    int plusCount = arr[i+1];
                    int minusCount = arr[i-1];
                    arr[i+1] = 0;
                    arr[i]--;
                    arr[i-1] = 0;

                    ret = max(ret,rec(i));

                    arr[i+1] = plusCount;
                    arr[i]++;
                    arr[i-1] = minusCount;
                }
                ret += cur == -1? 0:cur;

                return ret;
            }
        public:
            int deleteAndEarn(vector<int>& nums) {
                for(int e : nums){
                    arr[e]++;
                    maxValue = max(maxValue, e);
                    minValue = min(minValue, e);
                }

                return rec(-1);
            }
        };
        ```
    ---
    > 놓친 부분
        > 1. 하나의 숫자를 선택했을때, 그 숫자 중 하나만 선택할 이유는 없다. 모두를 선택하는게 최대값을 가진다
        > 2. 백트래킹을 할 필요없이 순서대로 봐도된다
    2. DP
        > 이렇게 보면, HouseRobber 문제와 동일한 문제이다
        > 현재 값을 선택하면 이전 값은 선택할 수 없다
        1. 상태 정의
            - dp[i] : i까지 검사해봤을때 최대값
        2. 현재 상태에서 가능한 선택
            - i번째를 선택하는가
            - i번째를 선택하지 않는가
        => **dp[i] = max(dp[i-1],dp[i-2] + i * arr[i]);**
        ```cpp
        class Solution {
        public:
            int deleteAndEarn(vector<int>& nums) {
                int dp[10001];
                int arr[10001] = {0};
                int minValue = 0;
                int maxValue = 0;
                for(int e : nums){
                    arr[e]++;
                    maxValue = max(maxValue, e);
                    minValue = min(minValue, e);
                }

                dp[0] = 0;
                dp[1] = arr[1];
                for(int i = 2;i<=maxValue;i++){
                    dp[i] = max(dp[i-1],dp[i-2] + i * arr[i]);
                }

                return dp[maxValue];
            }
        };
        ```
