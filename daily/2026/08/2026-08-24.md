## 정리
### 코딩 테스트
- Non-overlapping Intervals
    - 문제 접근
        - 가장 먼저 탐욕법이 떠올랐다
            > 겹치는 요소를 최소화 = 겹치지 않는 요소를 최대화
            > 겹치지 않는 요소를 최대화하기 위해서는 현재 선택 가능한 요소 중에서 종료 시간이 가장 빠른 것을 선택한다
            > - 탐욕적 선택 속성 (탐욕적이지 않은 해가 있는지 확인하자)
            >   - 먼저 끝나지 않는 최적해가 있다고 가정해보자, 이를 먼저 끝나는 요소로 변경해도 최소한 최적해는 유지된다
    - 구현
        ```cpp
            class Solution {
            public:
                int eraseOverlapIntervals(vector<vector<int>>& intervals) {
                    vector<pair<int,int>> tmp;
                    for(auto i : intervals){
                        tmp.push_back({i[1],i[0]});
                    }
                    sort(tmp.begin(),tmp.end());

                    int last = -987654321;
                    int ret = 0;
                    for(auto t : tmp){
                        int s =t.second;
                        int e = t.first;
                        if(last <= s) last = e;
                        else ret++;
                    }
                    return ret;
                }
            };
        ```
