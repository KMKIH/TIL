## 정리

### 코딩 테스트
- 3Sum
    - 문제 정리
        - 원소를 3개 선택해서 합이 0이되는 조합을 구하자
    - 접근
        - 3개를 단순히 선택하면 nC3 => O(n^3)으로 시간 초과 가능성이 높다
        > 숫자를 하나 선택하고 나면, 내가 아는 2Sum문제가 나온다!
    - 최적화
        1. 1개를 미리 골라 놓고 나머지 2개를 선택하자
        2. 정렬을 하여 단순 탐색이 아닌 슬라이딩 윈도우가 가능하도록 하자
    - 회고
        - 초기 풀이에서 중복되는 조합을 넣어서 오답처리 되었다
        - 이를 해결하기 위해 set을 사용했는데, 이렇게 하면, 시간이 너무 오래 걸린다 (통과는 했지만 1250ms가 나왔음...)
        - 풀이 과정 자체에서 중복을 없애야한다
            - 정렬이 되어있으므로, 이전값과 같은 값이라면 패스한다
            - 투포인터를 이동할때, 같은 값이면 이동시킨다
    - 코드
        ```cpp
            class Solution {
            public:
                vector<vector<int>> threeSum(vector<int>& nums) {
                    vector<vector<int>> ret;

                    // 인덱스가 아닌 수 자체가 정답이 되므로, 정렬을 해서 숫자 크기에 의한 접근이 가능하게 하자
                    sort(nums.begin(), nums.end());

                    // 일단 수 1개를 선택한다
                    for(int i = 0; i < nums.size(); i++){
                        // nums[i] : 첫번째 수
                        if (i > 0 && nums[i] == nums[i-1]) continue;
                        
                        int l = i+1;
                        int r = nums.size()-1;
                        while(l<r){
                            int res = nums[i] + nums[l] + nums[r];
                            // cout << i << ", " << l << ", " << r << "=> " << res << "\n";
                            if(res == 0){
                                ret.push_back({nums[i], nums[l], nums[r]});

                                int lv = nums[l];
                                int rv = nums[r];

                                while (l < r && nums[l] == lv) l++;
                                while (l < r && nums[r] == rv) r--;
                            }
                            else if(res < 0){
                                l++;
                            }
                            else if(res > 0){
                                r--;
                            }
                        }
                    }
                    
                    return ret;

                    // 하나의 수를 선택한다 : N
                    // 두개의 수를 투포인터를 통해 선택한다 : N (양끝에서 원소를 한번씩 탐색하므로)
                    // => O(N^2)
                }
            };
        ```
