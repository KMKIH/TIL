### 코딩 테스트
- Find All Anagrams in a String
    > 고정 크기 슬라이딩 윈도우에 대한 이해가 부족했다!

    - 문제 정리
        - 문자열 s와 p가 주어졌을때, s내에 p의 아나그램을 찾는 문제
    - 문제 접근
        - 모든 경우에 대해서 아나그램을 구하면 중복되는 연산이 많아진다
        - 슬라이딩 윈도우를 이용해서 윈도우의 끝부분에 대해서만 연산을 하여 연산의 수를 줄이자
    - 코드
        ```cpp
        class Solution {
        public:
            vector<int> findAnagrams(string s, string p) {
                vector<int> ret;

                vector<int> target(26,0);
                vector<int> window(26,0);

                for(int i = 0; i < p.size(); i++){
                    target[p[i]-'a']++;
                }

                int l = 0;
                for(int r = 0; r < s.size(); r++){
                    // Add
                    window[s[r]-'a']++;

                    // Remove
                    if(r-l+1 > p.size()){
                        window[s[l++]-'a']--;
                    }

                    // 조건 검사
                    if(window == target) {
                        ret.push_back(l);
                    }
                }
                return ret;
            }
        };
        ```
