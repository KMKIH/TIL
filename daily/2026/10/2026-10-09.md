## 정리

### 코딩 테스트

- Move Zeroes
    - 문제 정리
        - 배열에서 0을 모두 뒤로 이동시킨다.
        - 0이 아닌 원소들의 상대적인 순서는 유지해야 한다.
        - In-place로 해결해야 한다.

    - 1차 접근
        - In-place 조건을 보고 버블 정렬 방식으로 접근했다.
        - 0을 발견하면 오른쪽 원소와 Swap한다.
        - 이 과정을 반복하여 모든 0을 배열의 뒤쪽으로 이동시킨다.
        - 시간복잡도: O(N²)
        - 공간복잡도: O(1)

    - 1차 구현
        ```cpp
        class Solution {
        public:
            void moveZeroes(vector<int>& nums) {
                int n = nums.size();
                for(int i = n-1; i >= 0; i--){
                    for(int j = 0; j < i; j++){
                        if(nums[j] == 0)swap(nums[j],nums[j+1]);
                    }
                }
            }
        };
        ```

    - 2차 접근
        - 0을 오른쪽으로 이동시키는 대신, 0이 아닌 원소를 왼쪽으로 이동시키자.
        - `last`를 사용하여 다음 원소가 배치될 위치를 관리한다.
            1. 배열을 순회한다.
            2. 현재 원소가 0이 아니라면 `last` 위치와 Swap한다.
            3. `last`를 증가시킨다.
        - 시간복잡도: O(N)
        - 공간복잡도: O(1)

    - 2차 구현
        ```cpp
        class Solution {
        public:
            void moveZeroes(vector<int>& nums) {
                int n = nums.size();
                int last = 0;
                for(int i = 0; i < n; i++){
                    if(nums[i] != 0) swap(nums[i],nums[last++]);
                }
            }
        };
        ```

    - 회고
        - 1차 풀이에서는 0을 뒤로 밀어내는 방식으로 접근했다.
        - 하지만 반대로 0이 아닌 원소를 앞으로 배치하면 한 번의 순회로 해결할 수 있었다.
        - **원소를 이동시키는 대신, 원소가 배치될 위치를 관리하는 방식으로 생각해 보자.**
