### CS 공부
- (cpp) 정적 바인딩과 동적 바인딩에 대한 이해
    - **정적 바인딩**: 호출 코드의 정적 타입을 기준으로 어떤 함수를 부를지 컴파일 타임에 결정하는 것
    - **동적 바인딩**: 실제 객체 타입을 기준으로 런타임에 호출할 함수를 결정하는 것
        - 조건
            - 기반 클래스 포인터 또는 참조를 통해 호출해야 한다
            - 기반 클래스에 **virtual** 함수가 있어야 한다
    - 호출 순서
        1. 클래스를 명시한 경우, 명시된 클래스의 함수를 호출한다
        2. 동적 바인딩 조건이 만족했다면 동적 바인딩을 한다
        3. 이외의 경우 정적 바인딩을 한다

- 템플릿
    - **설명**
        - 코드를 찍어내기 위한 틀이다
        - 컴파일 시점에 실제 사용된 타입에 맞춰서 함수/클래스 코드가 생성된다
    - **장점**
        - 코드 재사용성이 높다
        - 타입 안정성
    - **단점**
        - 코드가 길어진다 → 컴파일 시간이 길어진다
        - 에러 메세지가 복잡하다
    - 대표적인 예시
        - vector<int>
        - vector<float>
    - **일반함수와의 우선순위**
        - 일반함수가 우선 호출된다
        - 자료형을 명시하여, 명시적 호출 가능
            - function<int>(10)
