## 오늘 배운 내용
### 코딩테스트
- Asteroid Collision
    - 문제 정리
        - 행성의 크기와 방향이 주어진다 (속도는 일정하다)
        - 충돌시 크기가 작은 행성은 사라진다
        - 충돌시 크기가 같으면 두 행성 모두 사라진다
        => 남은 행성을 구해라
    - 접근방법
        >  배열을 순회하며 각 행성의 충돌에 대해 계산하자
        >  => 가장 최근 행성과 충돌 처리를 하므로 Stack을 이용한다
        1. Stack이 비어있다면, Push
        2. Top이 음의 방향이고 현재 행성이 양의 방향이면, Push (만날 수 없다)
        3. Top이 양의 방향이고 현재 행성이 양의 방향이면, Push (만날 수 없다)
        4. Top이 양의 방향이고 현재 행성이 음의 방향이면
            - 현재 행성이 사라질때까지 Top과 비교해서 Pop한다
    - 구현
        ```cpp
        class Solution {
        public:
            vector<int> asteroidCollision(vector<int>& asteroids) {
                int n = asteroids.size();

                stack<int> s;

                for(int i = 0; i < n; i++){
                    int cur = asteroids[i];

                    if((s.empty() && cur < 0) || cur > 0) s.push(cur);
                    else {
                        while(true){
                            if(s.empty() || s.top() < 0){
                                s.push(cur);
                                break;
                            }
                            if(s.top() == -cur){
                                s.pop();
                                break;
                            }
                            
                            if(s.top() < -cur) s.pop();
                            else break;
                        }
                    }
                }

                vector<int> ret;
                while(s.empty()==false){
                    ret.push_back(s.top());
                    s.pop();
                }
                reverse(ret.begin(),ret.end());
                return ret;
            }
        };
        ```
    - 회고
        - 각 행성은 Stack에 최대 한 번 Push되고 최대 한 번 Pop되므로 전체 시간복잡도는 O(N) 이다
