## 오늘 배운 내용
### 코딩테스트
- Search in Rotated Sorted Array
    - 문제 요약
        - Rotated로 정렬된 배열에서 이분 탐색하기
    - 문제 접근
        1. 기준점을 찾는다 
            - 이분 탐색을 통해서 처음으로 값이 감소하는 지점을 찾는다
        2. 기준점을 이용해서 이분탐색을 한다
            - 일반적인 이분탐색을 하듯이 진행한다
            - 실제 값을 찾을때 기준점을 통해서 찾는다
    - 구현
        ```cpp
        class Solution {
        private:
            int size;
            int realLIdx;
        public:
            int searchLeftValueIdx(vector<int>& nums){
                int l = 0;
                int r = nums.size()-1;
                int m;
                while(l<r){
                    if(nums[l] <= nums[r]) return l;
                    m = l + (r-l)/2;
                    if(nums[l] <= nums[m]){
                        l = m+1;
                    }
                    else {
                        r = m;
                    }
                }
                return r;
            }
            int getRealIdx(int idx){
                return (idx + realLIdx)%size;
            }
            int search(vector<int>& nums, int target) {
                size = nums.size();
                // 1. find L (by binary search) - 숫자가 감소하는 첫번째 구간
                realLIdx = searchLeftValueIdx(nums);

                // 2. 0부터 시작한다고 가정하고 해당하는 target 찾기, 1번에서 구한 값으로 원래 인덱스 계산
                int l = 0;
                int r = size-1;
                int m, realIdx;
                while(l<=r){
                    m = l + (r-l)/2;
                    realIdx = getRealIdx(m);
                    if(nums[realIdx] == target) return realIdx;
                    if(nums[realIdx] < target){
                        l = m + 1;
                    }
                    else {
                        r = m - 1;
                    }
                }
                return -1;
            }
        };
        ```
    - 다른 풀이
        > 첫 번째 접근은 문제를 내가 아는 일반적인 이분 탐색 형태로 바꾸는 방식이었다. 하지만 배열 전체가 정렬되어 있지 않아도, 현재 상태에서 target이 어느 쪽에 있는지 판단할 수 있다면 이분 탐색을 적용할 수 있다.
        1. 매 이분 탐색 단계에서 왼쪽 절반 또는 오른쪽 절반 중 하나는 반드시 정렬되어 있다.
        2. 정렬되어 있는 절반의 범위에 target이 포함된다면, 해당 절반으로 탐색 범위를 줄인다.
        3. 포함되지 않는다면 반대쪽 절반으로 탐색 범위를 줄인다.
        4. 줄어든 구간에서도 같은 과정을 반복한다.
