# Today I Learned

게임 클라이언트 개발자를 준비하며 하루 동안 한 일과 새롭게 배운 내용,
문제를 해결한 과정을 기록하는 저장소입니다.

짧은 학습과 작업 과정은 `daily`에 남기고, 다시 참고할 가치가 있는 내용은
`notes`에 주제별로 정리합니다. 그중 다른 사람과 공유할 만한 내용은
[티스토리](https://sydz.tistory.com/)에 작성합니다.

## 구성

```text
TIL/
├─ README.md
├─ daily/
│  └─ YYYY/
│     └─ MM/
│        └─ YYYY-MM-DD.md
└─ notes/
```

### `daily`

날짜별 학습 및 개발 기록입니다.

- 오늘 한 일
- 새롭게 배운 내용
- 막힌 부분과 해결 과정
- 이어서 확인할 내용
- 관련된 `notes` 문서

공부하거나 기록할 내용이 있는 날에만 작성하며, 매일 커밋하는 것 자체를
목표로 삼지는 않습니다.

### `notes`

나중에 다시 참고하거나 다른 상황에도 적용할 수 있는 내용을 주제별로
정리합니다.

- Unity
- C# 및 C++
- 게임 개발
- 컴퓨터 과학
- 자료구조와 알고리즘
- 문제 해결 및 트러블슈팅

카테고리는 실제 문서가 생길 때 추가하고, 내용이 겹치거나 지나치게
세분화되지 않도록 관리합니다.
