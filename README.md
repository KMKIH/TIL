# Today I Learned

하루 동안 진행한 작업과 새롭게 배운 내용, 문제를 해결한 과정을 기록하는 저장소입니다.

간단한 학습 내용과 작업 기록은 daily에 정리하고, 그중 따로 정리해 공유할 만한 내용은 [티스토리](https://sydz.tistory.com/)에 작성합니다.

## 구성

```text
TIL/
├─ README.md
└─ daily/
   └─ YYYY/
      └─ MM/
         └─ YYYY-MM-DD.md
```

### `daily`

날짜별 학습 및 개발 기록입니다.

- 오늘 한 일
- 새롭게 배운 내용
- 막힌 부분과 해결 과정
